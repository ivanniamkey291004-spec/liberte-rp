# Liberté RP

Prototype HTML 3D d’une ville RP inspirée de Fort-Duval, jouable dans un navigateur.

## Lancer le jeu

Ouvre `index.html` directement dans ton navigateur ou utilise GitHub Pages.

## Contrôles

- **Clavier** : ZQSD / WASD ou flèches
- **Courir** : Maj
- **Caméra** : souris
- **Interagir** : E
- **Mobile** : joysticks et boutons tactiles

## Technologies

- HTML
- CSS
- JavaScript
- Three.js
